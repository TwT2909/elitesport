# EliteSport — Система управления клиентами фитнес-клуба

## Краткое описание

Веб-приложение для управления клиентами фитнес-клуба. Позволяет вести базу клиентов, управлять тарифами, отслеживать платежи и управлять пользователями системы. Реализована поддержка нескольких языков (русский и английский). Доступ в систему разграничен по ролям: администратор, менеджер, оператор.

---

## Системные требования

- Windows 10 / 11
- Python 3.11 или 3.12 (рекомендуется, с 3.13 могут быть проблемы)
- PostgreSQL 14 или выше
- pgAdmin 4 (для управления базой данных)
- Подключение к интернету для установки библиотек

---

## Инструкция по установке

### 1. Установить Python

Скачать Python 3.11 с официального сайта:  
https://www.python.org/downloads/release/python-3119/

При установке обязательно поставить галочку **"Add Python to PATH"**.

---

### 2. Установить PostgreSQL

Скачать PostgreSQL с официального сайта:  
https://www.postgresql.org/download/windows/

При установке запомнить пароль для пользователя `postgres`.

---

### 3. Создать базу данных

Открыть pgAdmin, подключиться к серверу и создать базу данных:

- **Имя базы:** `fitness_club`
- **Пользователь:** `postgres`
- **Пароль:** `424242`
- **Порт:** `5432`

---

### 4. Распаковать проект

Распаковать архив `gogo.zip` в удобную папку, например:  
`C:\Users\student\Desktop\elitesport`

---

### 5. Создать виртуальное окружение

Открыть PowerShell в папке проекта и выполнить:

```
python -m venv venv
```

Разрешить выполнение скриптов (один раз):

```
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
```

Активировать виртуальное окружение:

```
venv\Scripts\activate
```

В начале строки должно появиться `(venv)`.

---

### 6. Установить зависимости вручную

Выполнить команды по одной:

```
pip install fastapi==0.115.0
pip install uvicorn==0.30.6
pip install sqlalchemy==2.0.35
pip install psycopg2-binary==2.9.9
pip install alembic==1.13.2
pip install jinja2==3.1.4
pip install python-multipart==0.0.9
pip install "passlib[bcrypt]==1.7.4"
pip install itsdangerous==2.2.0
```

---

## Инструкция по запуску

1. Открыть PowerShell в папке проекта
2. Активировать виртуальное окружение:

```
venv\Scripts\activate
```

3. Запустить сервер:

```
uvicorn app.main:app --reload
```

4. Открыть браузер и перейти по адресу:

```
http://localhost:8000
```

5. Войти в систему:
   - **Логин:** `admin`
   - **Пароль:** `admin123`
